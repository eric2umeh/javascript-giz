# JavaScript GIZ

JavaScript GIZ is a collection of beginner-friendly JavaScript projects created while studying Advanced Web Development (MERN).

The repository contains simple assignments and group projects that demonstrate JavaScript fundamentals through practical examples.

## Projects

### Assignment 1

- Shopping Cart System

### Group Project 1

- Student Grade Tracker

### Group Project 2

- Personal Budget Tracker

## Topics Covered

- Variables and Data Types
- Arrays and Objects
- Functions
- Conditionals
- Loops
- DOM Manipulation
- Event Handling
- Array Methods
  - forEach()
  - filter()
  - reduce()

## Purpose

This repository documents my JavaScript learning journey and serves as a resource for peer learning and classroom demonstrations. The projects are intentionally kept simple to help beginners understand core JavaScript concepts through practical exercises.

## Classroom & Peer Learning

These projects have been used during peer learning sessions and classroom presentations to introduce JavaScript fundamentals through hands-on coding exercises.

As the repository grows, this section will include:

- Presentation photos (where appropriate)
- Workshop materials
- Additional assignments
- Learning resources
- Student project examples

The aim is to create an open learning resource that supports beginners studying JavaScript and modern web development.
